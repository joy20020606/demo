# TOEIC 3000 單字練習

純前端的多益單字練習網頁，收錄 **3559 個多益核心單字**，零依賴、免安裝，直接用瀏覽器打開 `index.html` 即可使用。

## 功能

**四種練習模式**

| 模式 | 說明 |
|---|---|
| 英 → 中 | 看英文單字，從四個選項選出正確中文字義 |
| 中 → 英 | 看中文字義，選出正確的英文單字 |
| 拼字測驗 | 看中文字義與首末字母提示，輸入完整英文單字 |
| 單字卡 | 翻卡自評「記得／還不熟」，適合快速刷字 |

**出題範圍可自由組合**

- 難度等級：Level 1 基礎 / Level 2 進階 / Level 3 高階（可複選）
- 詞性：名詞、動詞、形容詞、副詞、介系詞、連接詞、代名詞、片語
- 題庫來源：全部單字 / 只練錯過的 / 我的收藏 / 尚未練過
- 題數：10、20、30、50 或全部

**學習輔助**

- **智慧排序**：答錯次數多、還沒練過的字會優先出現；連續答對 3 次以上的字降低出現頻率
- **精準干擾選項**：錯誤選項優先取用同詞性、同難度的單字，且自動排除與正解字義相同者，避免出現多個正確答案
- **同義字判定**：拼字題若寫出字義完全相同的同義字（如「精確的」寫成 accurate 而答案是 precise）也判定為正確
- **發音**：點 🔊 朗讀單字，或開啟「自動發音」讓每題自動播放（使用瀏覽器內建語音）
- **收藏**：⭐ 標記想加強的字，之後可只練收藏
- **鍵盤操作**：`1`–`4` 選答案、`Enter` 送出／下一題、單字卡用 `空白鍵` 翻卡、`1`／`2` 評分

**進度追蹤**

- 已練過 / 已精熟 / 待加強 / 正確率統計，以及「最需要加強的單字」排行
- 單字表支援中英文搜尋與等級、收藏、錯過、精熟等篩選
- 學習紀錄存在瀏覽器 localStorage（不會上傳），可匯出／匯入 JSON 備份
- 深色 / 淺色主題切換，手機版面自動適配

## 使用方式

直接開啟：

```bash
open toeic-vocab/index.html      # macOS
xdg-open toeic-vocab/index.html  # Linux
```

或起一個本機伺服器：

```bash
cd toeic-vocab && python3 -m http.server 8000
# 瀏覽 http://localhost:8000
```

## 檔案結構

```
toeic-vocab/
├── index.html      # 頁面結構
├── styles.css      # 樣式（含深色模式）
├── app.js          # 練習邏輯、進度記錄、統計
└── data/words.js   # 單字庫（3559 字）
```

## 單字庫格式

`data/words.js` 匯出 `window.WORDS`，每筆為 `[單字, 詞性, 中文字義, 難度]`：

```js
["negotiate", "v", "協商", 2]
```

難度 `1` = 基礎、`2` = 進階、`3` = 高階。要增修單字直接編輯這個檔案即可，程式會自動反映在題庫、篩選器與統計中。

## 已知限制

- 發音依賴瀏覽器的 SpeechSynthesis API，部分環境可能沒有英文語音可用
- 學習紀錄綁定單一瀏覽器，換裝置請用「匯出／匯入紀錄」轉移
- 單字採「中文字義 + 詞性 + 難度」標註，未包含例句與音標
