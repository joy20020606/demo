## 拍攝建議

- **解析度**：建議 1600×1000 左右（4:3 比例），太寬 README 顯示會被縮太小
- **格式**：PNG（不要 JPG，文字會糊）
- **內容**：Kanban 那張要有真實的卡片資料，至少：

  - PROPOSAL 欄 1 張
  - WON 欄 1 張（卡片要顯示 🔒 已結案）
